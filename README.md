# Population of Major Cities in Iran

A simple Python data visualization project showing the population of major cities in Iran on a map.

## Cities

* Tehran
* Tabriz
* Isfahan
* Shiraz

## Technologies

* Python
* Matplotlib
* Basemap

## Description

This project uses geographic coordinates and population data to visualize the population of four major cities in Iran.

The size of each circle represents the population of the city.

## How to Run

Install the required libraries:

```bash
pip install matplotlib basemap
```

Then run:

```bash
python population_map.py
```
